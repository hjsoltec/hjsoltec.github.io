# HJSol 홈페이지 기능별 브로셔 반영

- 기준일: 2026-11-10
- 배포 소스 버전: 1.2.0
- 입력: HJSolAI_브로셔_편집본.pptx, 116쪽
- 원본 PowerPoint 파일은 바이트 단위로 그대로 포함했습니다.

## 반영 범위

| 제품 | 원본 페이지 | 제품별 PDF | 기능별 화면 |
| --- | --- | --- | --- |
| HJSolAISP | 3–57 | 55쪽 | 53개 |
| HJSolAIRND | 58–107 | 50쪽 | 49개 |
| HJSolAIEG | 108–115 | 8쪽 | 6개 |

메인의 솔루션 설명과 대표 화면, 기능별 브로셔 소개를 보강했습니다.
제품 상세에는 기능 분류·검색·6개 단위 페이지 이동·확대 대화상자·이전/다음 화면·이미지 새 창 보기를 추가했습니다.
자료실에는 통합 PDF·원본 PowerPoint와 제품별 PDF 3개를 등록했습니다. 통합 자료는 각 제품 필터에서도 표시합니다.

HJSolAISP는 서버·GPU·DB·슬로우쿼리·경고·원격접속·감시 정책과 AI 업무 지원을 중심으로 정리했습니다.
HJSolAIRND는 시험평가·작업지시서·학습·예측·미세증분·SHAP·지식관리·연구 보고서를 반영했습니다.
HJSolAIEG는 공통 로그인·업무 선택·포털·홈페이지·내부업무·AI 도우미를 반영했습니다.
기존 ETL 설명은 유지하되 이번 브로셔 화면 수에는 포함하지 않았습니다.

기존 URL, 브로셔·매뉴얼·회사 Word 문서, 이메일과 전화번호 제거 상태를 유지했습니다.
브로셔의 장치 지원·미수집 지표·AI 미연결 예시를 기능 보장으로 해석하지 않도록 설명에 반영했습니다.

## 출처와 무결성

`docs/BROCHURE_SOURCE_20261110.json`에 원본 PPTX 해시, 제품별 원본 페이지 범위, 108개 화면과 그림 출처, 다운로드 5개의 해시를 기록했습니다.
홈페이지 화면 이미지는 PPTX 안의 그림 원본을 추출했습니다. 한 페이지에 그림이 여러 개 있으면 대표 그림을 사용하며 전체 구성은 PDF에서 확인할 수 있습니다.
`npm run verify`는 원본 PPTX와 그림의 바이트, 정적 출력의 파일 복사, 갤러리·검색·다운로드 경로를 확인합니다.

## 검증

- TypeScript 검사와 Next.js 프로덕션 빌드 통과.
- HTML 17개, 내부 링크·자산 703개, 공개 자료 21개 검증.
- canonical·OG·설명·H1·JSON-LD·FAQ와 사이트맵 24개 URL 검증.
- 기능 화면 108개의 원본·내보내기 해시 및 다운로드 5개 검증.
- PDF 전체 116쪽과 제품별 55 / 50 / 8쪽 확인. 전체 페이지 축소 렌더와 개요 페이지를 시각 검토.
- 데스크톱 브라우저에서 솔루션 전환·제품 상세·AISP 분류·페이지 이동·검색 빈 결과·복원·확대·다음 화면·Escape 닫기, AIRND 지식관리 검색, AIEG 자료실 필터 확인.
- 작은 화면용 메뉴·카드·필터·대화상자 CSS를 포함했습니다. 브라우저 기기 에뮬레이션 검증 여부는 최종 배포 ZIP의 VERIFICATION.json을 확인하세요.
- 관리형 미리보기의 --host/--strictPort 인수와 Next.js 개발 명령의 호환을 위해 scripts/dev.mjs를 추가했습니다. 기본 npm run dev는 기존처럼 동작합니다.

## 적용

기존 hjsoltec.github.io 소스 구조를 그대로 사용합니다.

1. Node.js 22 이상에서 npm ci
2. npm run typecheck
3. npm run build
4. npm run verify
5. 기존 GitHub Pages workflow로 out/ 배포

Sites는 기존 프로젝트와 접근 권한을 유지해 갱신합니다. GitHub Pages 직접 업로드·배포는 이 작업에 포함되지 않습니다.
