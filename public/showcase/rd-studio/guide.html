화면별 사용자 가이드

데이터셋 준비부터 학습과 예측, 문헌 조회, 검토·시험 초안까지 사용하는 순서를 설명합니다. 화면은 구현 기능을 바탕으로 재구성했으며 설치 환경에 따라 메뉴 배치와 제공 기능이 달라질 수 있습니다.

사용 전 준비

사용 전 준비

사용자 권한과 데이터 범위를 먼저 확인합니다

  1. 접근 권한 — 분석예측·시험평가의 사용자 역할을 확인합니다
  2. 데이터 준비 — 샘플 식별자, 원재료 투입량과 실측 물성을 준비합니다
  3. 모델과 AI — 수치 예측 모델과 대화용 AI 공급자를 구분합니다
  4. 고급 기능 — 연구·승인 기능은 관리자 설정과 권한을 확인합니다

자료 업로드만으로 대화용 LLM 자체를 재학습하지 않습니다

화면과 현재 작업

화면과 현재 작업 확인

기본 동선: 분석예측 / AI 도우미

  1. 새 작업 또는 최근 작업을 엽니다
  2. 현재 데이터셋과 버전, 학습 방식을 확인합니다
  3. 질문을 입력하거나 파일을 첨부합니다

표시한 수치와 대화는 가상 예시입니다

파일 업로드

파일로 데이터셋 만들기

기본 동선: AI 도우미 / 데이터셋 선택 / 파일 업로드

  1. 기존 업로드 형식에 맞는 파일을 선택합니다
  2. 샘플·원재료·물성 열과 단위를 확인합니다
  3. 미측정 값과 제외 사유를 확인한 뒤 확정합니다

서로 다른 실측 샘플을 같은 샘플로 합치지 않습니다

실험 DB 선택

실험 DB에서 자료 선택

기본 동선: AI 도우미 / 데이터셋 선택 / 실험 DB

  1. 원재료·물성 카테고리와 시험조건을 선택합니다
  2. 조회 결과에서 사용할 자료를 선택합니다
  3. 제외 항목과 학습 가능 물성을 확인하고 확정합니다

원본 실험 DB는 조회 전용으로 사용합니다

저장 데이터셋

저장 데이터셋 재사용

저장된 자료의 이름·버전·출처를 확인합니다

  1. 저장 데이터셋 목록에서 자료를 선택합니다
  2. 샘플 범위와 선택 물성을 확인합니다
  3. 현재 작업에 연결하고 학습 방식을 확정합니다

최신 실험 자료를 쓰려면 다시 추출·저장한 데이터셋을 선택합니다

작업 구분

작업과 데이터셋 구분

다른 자료는 새 작업에서 시작할 수 있습니다

  1. 다른 데이터셋 선택 시 새 작업 시작을 사용합니다
  2. 같은 대화에서 바꾸려면 현재 작업 교체를 선택합니다
  3. 진행 중 분석은 완료하거나 취소한 뒤 교체합니다

동일 자료와 동일 설정의 재선택은 기존 연결을 유지합니다

학습과 결과

학습 방식 선택

물성별 독립 학습과 샘플 단위 비교를 선택합니다

  1. 독립 학습은 물성별 모델을 학습합니다
  2. 샘플 단위 비교는 독립·공동 후보를 비교합니다
  3. 선택을 확정하고 학습 진행 상태를 확인합니다

공유 DNN은 알고리즘 승인·활성화 후 선택할 수 있습니다

학습 완료 후 확인

물성별 후보와 검증 결과를 확인합니다. 데이터셋 전체의 저장 이력에는 다른 작업에서 실행한 결과도 포함될 수 있으므로 현재 작업의 모델 표시와 구분합니다.

검증 지표

검증 지표 읽기

같은 물성·단위·평가자료 안에서 비교합니다

항목뜻확인 내용
MAE평균 절대 오차낮을수록 평균 오차가 작음
RMSE큰 오차에 더 민감한 지표큰 예측 오차를 함께 확인
R²기준 평균 대비 설명 정도0 미만도 가능하며 단독 판단 지양
예측구간새 관측의 가능한 값 범위제공 조건·실제 포함률·범위 확인

모델 선택과 최종 평가 자료를 구분하고 실제 시험으로 확인합니다

예측과 추천

물성 예측과 배합 추천

기본 동선: 현재 데이터셋의 분석·예측·추천 실행

  1. 원재료 투입량과 조건을 입력합니다
  2. 물성 목표·허용 범위와 제약조건을 확인합니다
  3. 예측값과 적용 범위를 검토한 뒤 후보를 선택합니다

예측 결과는 실측이나 실제 시험 합격을 뜻하지 않습니다

미세증분

미세증분과 대체 후보 검토

같은 모델로 입력 변화의 영향을 비교합니다

  1. 변경 원재료와 증분 범위를 지정합니다
  2. 고정 조건과 수량 기준을 확인합니다
  3. 치환 후보는 TDS·사용 근거를 검토하고 예측합니다

새 원료나 관측 범위 밖 입력은 추가 검토와 실험이 필요합니다

문헌과 원문

TDS와 문헌 근거 확인

기본 동선: 연구 지식베이스 / 논문·특허·내부 실험보고서

  1. 문서와 출처, 보존 상태를 확인합니다
  2. 전체 원문 보기에서 추출 원문 또는 PDF를 엽니다
  3. 원본 다운로드로 보존 파일을 확인합니다

확보한 본문과 초록만 있는 자료를 구분합니다

조성 변경·검토

조성 변경과 독립 검토

원본과 변경 이유를 Revision별로 보존합니다

  1. 기준 결과를 가져와 원본 Revision을 보존합니다
  2. 변경 조성과 이유를 기록하고 다시 예측합니다
  3. 독립 검토자가 현재 Revision을 확인합니다

입력이 바뀌면 과거 검토 완료 상태를 그대로 승계하지 않습니다

시험 초안

시험평가 초안 연결

선정 Revision의 시험 계획에서 진행합니다

  1. 자재와 시험항목을 실제 활성 마스터에 연결합니다
  2. 수량·단위·조건과 초안 미리보기를 확인합니다
  3. 사용자 확인 후 초안을 생성하고 기존 절차로 의뢰합니다

초안 생성과 정식 시험 의뢰·승인을 구분합니다

보존과 내보내기

결과 보존과 내보내기

데이터와 모델 실행의 연결을 유지합니다

  1. 데이터셋 — 입력 스냅숏과 자료 버전을 보존합니다
  2. 모델 실행 — 사용한 학습 방식과 결과·검증 보고서를 확인합니다
  3. 다운로드 — 기존 결과·데이터셋 Excel 내보내기를 사용합니다
  4. 검토 이력 — 변경 사유와 검토·시험 연결 기록을 함께 확인합니다

이력 화면의 데이터셋 전체 결과와 현재 작업 결과를 구분합니다
